# External Blender files

`buildings_kit_10.blend` is a third-party modular buildings kit, downloaded from the internet (original source not recorded). It is used in the 3D Assets lecture as a reference for modular environment pieces.

It is kept here **read-only**: please do not save over it, because each new version of the file adds about 35 MB to the repository history. To modify it, work on a copy outside the repository.
